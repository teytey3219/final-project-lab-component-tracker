# Final Project: Laboratory Component Borrowing Tracker

A full-stack web application for tracking the borrowing and returning of laboratory components such as Arduino boards, sensors, breadboards, and jumper wires.

## Features

- Add a laboratory component borrowing record
- View all borrowing records
- Filter components that are still borrowed
- Update a record when an item is returned or its details change
- Delete incorrect records
- View summary information about borrowed and returned components

## Planned Technology Stack

- Front end: HTML, CSS, and JavaScript
- Back end: Node.js and Express.js
- Database: MongoDB
- Version Control: Git and GitHub
- Deployment: Render

## Record Information

Each borrowing record will include:

- Component name
- Borrower name
- Date borrowed
- Returned status
- Date returned, if applicable
